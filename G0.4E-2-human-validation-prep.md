## What was added

- `src/components/DebugInfo.tsx` (only file touched this phase):
  1. **Dev-only indicator + toggle** in the debug panel `<summary>` header:
     - Shows `Hard Leaf = BASELINE` or `Hard Leaf = HYBRID` (bold, yellow).
     - Button `→ hybrid` / `→ baseline` flips `HARD_LEAF_MODE_CONFIG.current` (the single
       source of truth from searchConfig).
     - Gated by `import.meta.env.DEV` — in a production build this whole branch is
       tree-shaken out (verified: the prod bundle contains 0 occurrences of the switch text).
  2. **`HARD_LEAF=` line added to the copyable debug dump** (e.g. `HARD_LEAF=BASELINE` or
     `HARD_LEAF=HYBRID`) so each human-validation game log records which leaf was active.

## How to use (human validation)

1. Run the game in DEV (`npm run dev`).
2. Open the Debug panel (🔧 调试).
3. Toggle `Hard Leaf = BASELINE → HYBRID` (or back) — the setting takes effect immediately on
   the next Hard cat turn (per-leaf eligibility still fail-closed).
4. Play a Hard game; at the end copy all debug info — the dump starts with
   `GAME N` / `RESULT:` / `HARD_LEAF=<BASELINE|HYBRID>`, followed by the full search snapshot.
5. Collect logs for both leaf modes (e.g. 5 baseline + 5 hybrid) for the human review.

Default on load remains **BASELINE** (production parity). The switch is a dev-only convenience;
the formal verification protocol and results are for the human reviewer.
