## A. 权威类（缺证据，不是缺代码）

- **现状**：`PPC-P1-TIME-02` 之后没有新的、正式的整回合 150ms 时限权威。本轮按要求**没有**跑任何 timing benchmark。
- **为什么开着**：`TOTAL_TURN_HARD_WALL = 150ms` 目前只有"构造性论证 + 单次诊断采样"支撑，缺一份在真实根集上的分布门（p95 / max / 超限比例）。
- **关闭需要**：一次预注册的 timing 实验（固定 fixture、串行、fresh repetition、记录每回合 `plannerCall` 与 `sidecar` 分解），并给出 `CEIL5(max(1.5·budget, 1.25·CAL_Q99))` 形式的判定。

### A2 `NEW_EFFICACY_AUTHORITY = NONE`
- **现状**：本轮 0 局自对弈、0 次 oracle、0 次 efficacy 主实验。四轮候选**没有任何**棋力提升主张。
- **为什么开着**：`PPC-P1-QUALITY-01` 改变了计划选择（6 个构造反例 6/6 翻转、2 个真实根计划变化），按项目纪律这属于**行为变更**，必须有独立的 efficacy A/B 才能谈强弱。
- **关闭需要**：预注册的 A/B（旧/新反向评分），固定根集、固定随机、固定预算。
- **注意**：本轮顺手发现一条相反方向的证据——见 B2，当前引擎在一个真实根上**多看见一个杀法**。这说明"行为变更"至少有一处是变强，但它**不是**系统性的棋力证据。

## C. 架构/类型风险（有设计但无守卫）

### C1 `catAiMove(state)` 省略时限身份时自铸窗口
- **现状**：`turnDeadline` 是可选参数。省略时 `planHardCatTurn` 自铸 `t0 + budget`——这是**文档化的契约**（独立调用＝拥有整个回合），生产三处 fallback 全部传了身份。
- **风险**：将来若有新入口直接调 `catAiMove`，会静默回到"每次 fallback 重新给 100ms"的老问题，且**没有任何东西会拦住它**。
- **关闭需要**：类型层双态（必填的 `TurnDeadlineIdentity | undefined`）、或一条"src 内 `catAiMove(` 调用必须带第二参数"的静态守卫测试。

### C2 `PPC-P1-ID-01` 缺 `SOURCE_MANIFEST.json`
- **现状**：四轮里唯一没有 manifest 的一轮，指纹只能靠 `PPC-P1-ID-01/REPORT.md` 与 `PPC-P1-TIME-01` 的 `p1IdCandidate` 互相印证（两处均与实测一致）。
- **风险**：建立 checkpoint 时 provenance 链会缺一环。
- **关闭需要**：补一份 `PPC-P1-ID-01/SOURCE_MANIFEST.json`（内容可从 REPORT.md + HEAD blob 重建，**不需要**改任何源码）。

### C3 地形编码的可比性边界
- **现状**：P1-ID 把 `trap`（`t`→`r`）与 `butter_spot`（`b`→`u`）的编码换掉，其余七种不变。默认地图不含这两种地形，所以 45 个 HV14 根 + 24 个人类根的 `stateKey` 全部不变（实测 key 长度 379，两臂相同）。
- **风险**：任何**含这两种地形**的历史 `stateKey` 字符串工件与新实现不再相等。本轮已扫描现有工件，未发现此类；但这是一条隐含前提，应写进 P1-ID 的结论范围。
- **关闭需要**：文档化（一句话），或对将来新增工件在生成时记录地形集合。

## D. 文档精度类（不影响正确性）

### D1 `PLAN_ACTION_BOUND_PROOF.md §3` 的定义域表述
- **现状**：§3 写 "the move budget is a free integer"，未限定**非负整数**，也未讨论小数 `catMovesLeft`。代码里 `catTurnMoveBudget` 是 `!isFinite || <=0 → 0`，否则 `Math.floor`；§4 只覆盖 `NaN / ±∞ / -3 / 0`。
- **正确性**：没有缺口。小数情形取整只会**收紧**上界（`M=2.5` 时真实步数至多 2，未取整上界 4.5，取整后 4 ≤ 4.5），不可能截断合法计划。
- **关闭需要**：§3 补一句"定义域为非负整数；非整数预算先 `floor`，只会收紧上界"。纯文档改动。

### D2 异常输入边界无门
| 输入 | 现状 | 门 |

| 极大 `catMovesLeft`（如 `1e6`） | 上界 `1.5M+1`，DP memo key 不含剩余容量故仍正确 | 无 |
- **关闭需要**：两条 fixture（非法/退化状态），不必进默认套件。
