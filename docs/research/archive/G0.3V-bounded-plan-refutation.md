# G0.3V — Bounded Adversarial Plan Refutation

Data: `post-g03h-real-failure-5games.txt` (26 real cat-turn roots, SNAPSHOT_JSON
authoritative). No production changes, no commits. Forensic only.
Tooling: `g03v.mts` (bounded adversarial plan-refutation probe + cap sweep +
G4 causal gate + G1 controls + G2/G5 secondary + false-positive audit + 500ms
benchmark + 26-root overhead; evidence `g03v-out.json`).

---

## 0. Reframing (spec §0)

G0.3V does not ask "is this plan safe?" — it asks:

> **"Can a small-budget probe find a real, legal mouse counter-strategy that
> breaks the plan's local tactical condition?"**

| term | meaning |
|------|---------|
| **PLAN_REFUTED** | a real legal mouse strategy tree was found such that every leaf (next-cat boundary) is LOCALLY UNANSWERABLE (or the mouse terminally won), with a full witness. Chance = AND over all positive-prob outcomes. |
| **CHANCE_MIXED** | a strategy reached a chance node but some positive-prob outcome was not (or not provably) unanswerable. NOT a refutation — keep searching. |
| **NO_REFUTATION_FOUND** | the bounded probe found nothing. NEVER written as SAFE / ESCAPE / ALL_PATHS_AVOID / NOT_FORCED / CAT_WIN. |

One-sided semantics (§21): approximation is ONLY in *which mouse paths were
explored*. Game rules, chance semantics and the local-tactical predicate are
EXACT. REFUTED = strong evidence; NO_REFUTATION_FOUND = unknown.

## 1. Bounded algorithm (§1–§7)

Per candidate cat plan (selector unchanged from G0.3U, frozen, MAX 6):

1. **Exact mouse root** from the full cat-turn replay of the plan.
2. **Bounded adversarial mouse-response search** (best-first / beam-like,
   §4): expands mouse atomic actions in **DANGER order** (G0.3R turn-aware
   geometry, §5 — never a per-root hack), with hard caps:
   - `MAX_PATHS` (16/32/64/128, §4) counts TURN_BOUNDARY / TERMINAL visits,
   - `MAX_CPU_MS` (5/10/20/40, §4) is a wall-clock deadline sampled per
     iteration + every 16 expansions,
   - `MAX_EXACT` caps the expensive L2 checks.
   - DECISION = OR (mouse picks the most dangerous continuation), CHANCE = AND
     (all outcomes must refute → otherwise CHANCE_MIXED), TERMINAL = mouse win
     is an immediate refutation.
3. **LOCALLY_UNANSWERABLE** (§6): on a next-cat boundary, the cat within its
   next 4 real moves can NEITHER capture the mouse NOR reach a **validated
   critical intercept cell** (a cell on a mouse→hole *shortest route* that the
   cat reaches strictly before the mouse under the G0.3R turn-aware time
   model). This is a tactical refutation signal — NOT mate / NOT forced loss.
4. **Win-threat gate**: a boundary is a refutation leaf only when the mouse is
   in a *scoring posture* there (carrying butter ∧ within one carrying-window
   of the hole). A butterless escape (skill dropped) does not break the plan's
   local tactical condition. Without this gate the RRRR control would be
   falsely refuted on its 7 skill-drop escapes (see §5).
5. **L1 / L2 two-layer (§7)**: every visited boundary gets a CHEAP L1 pre-score
   (cat simple-BFS capture distance ≤ 4 ⇒ provably respondable, no L2; plus the
   win-threat gate). Only the dangerous remainder runs **L2 EXACT_LOCAL**
   (`catCaptureOrInterceptWithin4` = legal-action cat BFS incl. push-box /
   trap-reclaim + validated route intercept). `exactLocalChecks` per candidate
   is kept at single digits on the causal pair (see §2).
6. **Refutation override (§10)**: only when baseline PLAN_REFUTED = TRUE and a
   candidate is NO_REFUTATION_FOUND; the frozen G0.3U lexicographic comparator
   then picks among the clean candidates.

**Fixed frozen parameters (§16):** `FIXED_PATHS=32, FIXED_CPU_MS=20,
FIXED_EXACT=16` — selected by the G4 causal pair after the cap sweep; every
candidate everywhere uses the same configuration (no per-root budget).

## 6. False-positive audit (§14)

G4 RRRR (GOOD) bounded probe: **NO_REFUTATION_FOUND** (45 paths, 24 distinct
boundaries, 0 exact checks — every boundary rejected at L1 or by the win-threat
gate). RRRR is NOT falsely PLAN_REFUTED.

The 24 NOT_FORCED boundaries (G0.3P escape-root certificate) were audited
against the raw L2 predicate: **7/24** are reported locally unanswerable
— all 7 are **skill-drop escapes** (mouse dropped butter via `mouseSkill`,
mouseHasButter=false: (7,8),(6,9),(9,8),(8,7),(8,9),(8,5),(7,6)). These are
`REFUTATION_CONFLICT_WITH_EXISTING_EVIDENCE` notes (the raw predicate says
"cat can't reach the mouse within 4", but the mouse is not a scoring threat).
This is NOT a statistical false-positive rate — NOT_FORCED ≠ safe. In the
*probe*, the win-threat gate excludes exactly these 7, so RRRR stays
NO_REFUTATION_FOUND. The audit therefore confirms the gate is load-bearing: it
prevents the exact false-positive class the spec §9 warned about.

## 9. Verdict

**`BOUNDED_PLAN_REFUTATION = WORTH_PRODUCTION_TRIAL`**

All §20 requirements met:

| §20 requirement | evidence |
|-----------------|----------|
| G4 causal BAD stably and quickly refuted | REFUTED at path rank 1, DDR witness, ≤5ms across every cap/cpu config |
| G4 GOOD not falsely refuted | NO_REFUTATION_FOUND across every cap/cpu config; RRRR control clean |
| 500ms product gate passes | 10/10 baseline, 10/10 sidecar, 10/10 BAD refuted, 10/10 not-BAD, 47–92ms/run |
| G1 control does not steal SAFE semantics | G1T2 6/6 REFUTED with no SAFE/ESCAPE terms; authoritative MOUSE_FORCED_WIN_PROVEN preserved; G1T1 NO_REFUTATION_FOUND consistent with UNRESOLVED |
| 26-root overhead controlled | avg 27ms / p90 82ms / max 127ms, 0% fallback, no explosion |

**Why it works where G0.3U exploded:** the cost driver in G0.3U was the exact
full-mouse-turn enumeration (D/E) per candidate — 4 763–309 003 raw paths and
11 k–17 k next-cat boundaries, each with an EXACT_LOCAL cat BFS. The bounded
probe instead (a) explores mouse continuations in danger order so the
refutation (e.g. DDR) is the FIRST boundary visited, (b) hard-caps paths and
CPU so a never-expanding search is guaranteed, (c) L1-pre-filters every boundary
so L2 EXACT_LOCAL runs only on the dangerous few (G4 pair: 1 exact check on
BAD, 0 on GOOD), and (d) gates refutation leaves by win-threat posture so
butterless escapes are never misreported. Result: a genuine refutation witness
with exact legality and exact chance semantics is found in milliseconds; a
missing witness is honestly NO_REFUTATION_FOUND, never SAFE.

**Honest limitations (kept one-sided):**
- CHANCE_MIXED paths are never claimed as refutations (§3) — a refutation that
  only exists through a chance node requires confirming ALL outcomes refute,
  which the single-witness best-first model does not do; those stay
  NO_REFUTATION_FOUND/CHANCE_MIXED (conservative, allowed).
- The 7 skill-drop boundaries flagged by the raw L2 predicate are excluded by
  the win-threat gate; this is a design decision (a butterless escape is not a
  broken plan), not a threshold tune — the selector, comparator and budgets are
  all frozen/G0.3U-unchanged.
- Bounded negative remains UNKNOWN by construction; the report never upgrades
  NO_REFUTATION_FOUND to a safety claim.

No production changes. No commits.
