### Exactness (forced branch vs serial rootActions)

**Measurement note (must be recorded):** serial `rootActions` non-first
branches store ALPHA-BETA BOUNDS, not exact values — the serial root MAX loop
searches later siblings with a narrowed window, so their recorded values may
be cut-offs (this was documented in G0.3M §5). The correct oracle for
"what an independent full-window worker computes" is the NO_AB (no-pruning)
expansion.

Re-verified with NO_AB truth:
- A g4t2: forced == NO_AB bit-identical (all 4) ✅
- B g1t2: forced == NO_AB bit-identical (all 3) ✅
- C g5t1: forced == NO_AB bit-identical (all 5) ✅
- D g3t5: forced == NO_AB bit-identical (both) ✅
- E g2t2: PV branch (ArrowRight) forced == serial exact ✅; serial root value
  == max(forced) ✅

Every forced full-window branch value/mate is the exact minimax; the search
mathematics are unchanged by the harness.

## 6. A / E long-tail verdicts

- **A (GAME4 T2)**: serial ~407-491ms. Ideal 4-worker = 421ms — fits 500ms in
  the ideal-lower-bound sense, but the improvement vs serial CPU is only
  1.17x. Parallel does NOT reliably pull A into the 500ms regime with margin
  (and real overhead from worker dispatch would erase the small gain).
- **E (G2T2 expensive)**: serial ~3.4–4.1s. Even IDEAL 4-worker = 1,859ms —
  **still >> 500ms**. Real workers (dispatch, TT isolation, load imbalance)
  only make it worse.

```
EXACT_PARALLEL_SEARCH = NOT_ENOUGH
```

**Why NOT_ENOUGH:**
1. **Overwork cancels the cores**: A/B pay 2.0x independent vs serial AB work;
   with only 2–5 root branches per root, there is not enough parallelism to
   overcome the lost cross-sibling alpha pruning. B's ideal 4-worker wall
   (656ms) is *worse* than serial CPU (628ms).
2. **Only C reaches ≥2x**; A is ~1.2x (serial 491ms → ideal 421ms), B is
   flat/worse.
3. **Long tail not solved**: E's ideal 4-worker = 1.86s, far above any 500ms
   budget — even perfect parallelism cannot bring the expensive roots into
   budget. Exact d2 work on E is simply too large.
4. Real-worker overhead (thread dispatch, TT partitioning, load imbalance)
   would only erode the modest ideal gains further.
