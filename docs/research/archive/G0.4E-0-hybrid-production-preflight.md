- Any predicate failure → **return evaluateForCat(state)** (baseline fallback).
- **HYBRID_STANDARD_MAP_ELIGIBILITY = DEFINED**; **CUSTOM_MAP = BASELINE_FALLBACK**.

## 5. Browser-safe weight packaging (§5) — READY

- The optimized weights are a 2.47 MB static JSON (808×128 + 128×64 + 64 + biases).
- **Recommended: generated readonly TS weight module** — emit the literal numbers as a
  checked-in `.ts` (e.g. `export const WEIGHTS = { W1f64: Float64Array.from([...]), ... }`),
  bundled by Vite. This preserves Float64 numerics exactly, requires zero runtime fetch,
  initializes once-at-import (sync), and the leaf stays synchronously callable.
  - Alternatives: (A) static JSON `import w from './weights.json'` + once-flatten is also viable
    (same size, Vite bundles JSON in); (B) binary Float64Array asset would need async fetch —
    REJECTED (no async in search).
- WEIGHT_PACKAGE_SIZE ≈ 2.4–2.5 MB raw (~600–900 KB gzip/brotli in bundle); INITIALIZATION_COST
  = one-time flatten at module load (few ms); BUNDLE_IMPACT = the weights are the dominant
  addition (no network at runtime).
- **BROWSER_WEIGHT_PACKAGING = READY** (recommendation: generated readonly TS module).

## 7. Fail-safe contract (§7) — DEFINED

`hybridEvaluateForCat(state)` (prototyped):
```
if (!eligible(state)) return evaluateForCat(state);
try {
  v = ValueNet(state);
  if (!finite(v)) return evaluateForCat(state);
  h = 0.5*tanh(eval/S) + 0.5*v;
  if (!finite(h)) return evaluateForCat(state);
  return h;
} catch { return evaluateForCat(state); }
```
Any model fault → production baseline. Game rules unaffected.
**FAIL_CLOSED_BASELINE_FALLBACK = DEFINED.**

## 9. Refutation interaction audit (§9) — PASS

- `runRefutationSidecar(state, plan, search.value, ...)` passes `search.value` as `baselineValue`
  to `pickOverrideCandidate` → `compareRefuteCandidates(a, b, baselineValue)`.
- In the comparator, `baselineValue` appears ONLY as a constant offset in a **pairwise
  tie-break**: `va = a.refuted ? baselineValue-1e9 : baselineValue` (likewise vb). Since both
  sides use the SAME constant, the −1e9 penalty and the baselineValue offset CANCEL in the
  relative comparison; the primary keys are refuted-state, respond-ratio, and worst-intercept
  margin — all **scale-independent exact-local checks**. No absolute `search.value` thresholds
  exist in the sidecar.
- **HYBRID_REFUTATION_SCALE_COMPATIBILITY = PASS.** (The Hybrid's different absolute magnitude
  does not reorder refutation; if future code ever thresholds on search.value magnitude, that
  must be re-audited — flagged, not changed.)

## 11. Reentrancy / scratch audit (§11) — PASS (with contract note)

- The optimized ValueNet uses module-global reusable scratch buffers. Production Hard is
  **synchronous, single-threaded**: one `planHardCatTurn` per cat turn inside
  `computeCatAiTrajectory` (turn-based game, no workers, no async, no concurrent or nested
  search). Reentrancy is therefore safe.
- **Contract for E1**: keep the Hard search synchronous and single-threaded. If any future
  async/worker/parallel path is introduced, per-evaluator scratch (instance-bound) is required.
- **REENTRANCY_SAFETY = PASS.**
