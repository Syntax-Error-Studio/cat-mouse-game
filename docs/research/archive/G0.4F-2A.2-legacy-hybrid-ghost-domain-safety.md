## 1. 已确认问题（representation aliasing）

G0.4F-2A/F2A.1 新增 `pendingButterSpawns` 与 `pendingButterPlacementDebt`（均为 game-affecting state）。但 frozen ValueNet 输入仍是 **808 dims**（8×10×10 channels + 8 globals），`buildProductionFeatures()` **不编码**这两个新字段；同时旧 `isHybridEligibleState()` 也不拒绝 ghost/debt states。

因此不同 ghost/debt state 可能映射到**完全相同**的 ValueNet input → **representation aliasing**：旧网络会把两个不同未来黄油局面当成同一局面打分。

**实测确认（test D/E）**：
- ghost=(2,3) 与 ghost=(7,6) 的 808 features **逐位相同**（frozen 808 不含 ghost）。
- debt=0 与 debt=2 的 808 features **逐位相同**（frozen 808 不含 debt）。

## 2. 最小安全规则（§2）

在 **单一路径** `isHybridEligibleState(state)`（src/game/ai/hybridLeaf.ts）新增：
```ts
if ((state.pendingButterSpawns?.length ?? 0) > 0) return false;      // visible ghost → ineligible
if ((state.pendingButterPlacementDebt ?? 0) > 0) return false;        // placement debt → ineligible
```
任何未完成的未来黄油信息（visible ghost 或 placement debt）都在旧 ValueNet 训练/representation domain 外 → **HYBRID_V1 与 HYBRID_V2 均 fail-closed → evaluateForCat(state)**。

## 3. 不改 V2（§3）

`hybridRouteLeaf.ts` **未复制** ghost eligibility —— V2 复用 `isHybridEligibleState()`，因此只改 single source。**SINGLE_ELIGIBILITY_SOURCE = PASS**。

## 4. 普通 canonical state 不变（§4）

`pendingButterSpawns=[]` + `pendingButterPlacementDebt=0` 且其余 canonical 条件满足 → `isHybridEligibleState=true`；ValueNet / Hybrid V1 / V2 数值完全不变（J 测试用冻结 G19/G17/G4 无 ghost fixtures 验证）。

## 5. Representation alias fixture（§5）

- A：同一 canonical state，ghost=(2,3)；B：同一 canonical state，ghost=(7,6)。
- `buildProductionFeatures(A) == buildProductionFeatures(B)`（预期，frozen 808 不含 ghost）。
- `isHybridEligibleState(A)=false`、`isHybridEligibleState(B)=false` → 旧网络不被错误使用。
- debt0 vs debt2：808 可相同，但 debt2 → ineligible。

## 6. V1 / V2 fallback（§6/§7）

- ghost state：`hybridEvaluateForCat(state) === evaluateForCat(state)`（严格相等，非 finite/approx）。
- debt state：同上。
- V2：`hybridRouteV2EvaluateForCat(state) === evaluateForCat(state)`（ghost/debt 均严格回退）。
- `evaluateHybridRouteV2Eligible` 内部 core 不需要改 —— production wrapper eligibility 负责挡住。

## 7. Resolver 三态不改（§8）

保持 `baseline` / `hybrid_standard_only` / `hybrid_route_v2_standard_only`，DEFAULT=baseline，`resolveHardLeaf` 映射不变。

## 8. 搜索规则仍看得到 ghost（§9）

**没有** 从 `stateKey` 删除 ghost、**没有** 从 simulator/search transition 隐藏 ghost、**没有** 把 ghost 当非 game-affecting。搜索仍按 F2A.1 完整规则演化（含 chance / debt / 边界实体化）。本轮只禁止旧 ValueNet 对 ghost/debt leaf 打分。
