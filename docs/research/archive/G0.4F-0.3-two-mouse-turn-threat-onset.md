## 2. 核心 threat oracle

```
FORCED_PICKUP_WIN_BY_NEXT_MOUSE_TURN(state)   // state = mouse-to-move, not carrying
  = ∃M1 (full mouse turn): M1 picks up butter AND M1 end still Playing (cat to move)
    ∀C1 (full cat turn defense): ∃M2 (full mouse turn): reaches GamePhase.MouseWins
```

- 全部用真实 `createEngineRuleSet` + `generateLegalSearchActions` + `simulateSearchAction`；
  完整支持 mouse step / skill / tunnel / chooseTunnel / trap / butter pickup / box 合法 / turn 结束。
- 完整 turn 用 `enumerateFullTurnLegacy`（turnBoundary.ts，已验证语义）枚举；M1/C1/M2 各阶段
  stateKey 去重 memo；early terminal prune；budget+wall cap。
- **探针正确性验证**：G16 T15（生产真实报 mate=mouse）mouse-side 状态下 `mouseCanWinThisTurn=true`、
  THREAT_D1/D2 均 mate=mouse → 探针能检出真实鼠胜。
- 计算现实：大棋盘 root（G28T9/G31T6）full-turn 枚举爆炸 → `COMPUTATIONALLY_INFEASIBLE`。

## 4. 完整猫回合枚举 + SAFE/UNSAFE 分类（任务 §7/§8）

对每个 suspect cat root 枚举所有合法完整猫回合 → 对 unique turn-end state 运行 oracle：
```
TOTAL_UNIQUE_CAT_END_STATES
SAFE_CAT_END_STATES   = forcedPickupWin2 == false
UNSAFE_CAT_END_STATES = forcedPickupWin2 == true
AVOIDABLE_AT_ROOT     = SAFE > 0
```

### G19T7（cat=(5,3), mouse=(7,2), 未持黄油）— 唯一完全枚举成功的 avoidable 候选
```
TOTAL_UNIQUE_CAT_END_STATES = 23
SAFE   = 2   (UUDD→cat(5,3) 留守, RRRD→cat(6,6))
UNSAFE = 21  (含 production ULDL→(5,1) 与 deep LLDD→(7,1))
AVOIDABLE_AT_ROOT = TRUE
production plan ULDL → unsafe (forced=true)
```
- **G19T7 是真正的 AVOIDABLE_STRATEGIC_FAILURE**：同一真实 cat root 存在 2 个 oracle-safe
  完整猫回合（cat 留守 (5,3) 争夺黄油 (6,3)，或占位 (6,6) 拦鼠冲洞走廊），但 production 走了
  unsafe 的 ULDL→(5,1)。
- production 的 unsafe end (cat (5,1)) 与 safe plan (cat (5,3)) 仅差 2 列——猫只要留守/靠右
  一格即可避免鼠的 2 回合强制胜。

## 6. 对 LATEST_AVOIDABLE_ROOT 检查 Hybrid（任务 §10）

### G19T7 leaf-score 分布（23 个 unique cat-turn end states）
| 类别 | n | Hybrid leaf 值域 |
|---|---|---|
| SAFE (forced=false) | 2 | avg 0.1387, [0.0581, 0.2193] |
| UNSAFE (forced=true) | 21 | avg 0.1193, [-0.0105, 0.2496] |

Hybrid 排名（1=最高）：
- production 的 unsafe end `UDLL→(5,1)`：**hybrid=0.2496（rank #1，全场最高）**
- safe plan `UUDD→(5,3)`：hybrid=0.2193（rank #3）
- safe plan `RRRD→(6,6)`：hybrid=0.0581（rank #18，接近垫底）

**关键发现 B：production 选的 unsafe 计划，其 end state 是 Hybrid leaf 全场评分最高的
(0.2496)；而真正 safe 的计划被评得更低（0.2193 / 0.0581）。Hybrid leaf 把"错误"的防守
局面排在最前——这不是搜索 horizon 问题（safe 计划在同一 depth-1 cat turn 内可达），而是
**leaf 表征盲区**：leaf 无法区分"猫留守 (5,3) 争夺黄油走廊"与"猫移到 (5,1) 放弃走廊"。

## 10. 最终判定（任务 §14）

```
F02_SCOPE_CORRECTED = PASS
CORE_COMPARABLE_ROOTS = 4
CORE_POSITIVE = 0
CORE_NEUTRAL = 3
CORE_WORSE = 1
GAMES_WITH_LATEST_AVOIDABLE_ROOT = 1   (G19 T7)
SEARCH_HORIZON_SUPPORTED = 0
LEAF_REPRESENTATION_SUPPORTED = 1      (G19T7 正式) + G17T2 CORE_WORSE 与 leaf 一致
BOTH_FAIL_BUT_LEAF_RANKS_SAFE = 0
UNRESOLVED = 2                          (G28T9, G31T6 计算不可行)
MOST_LIKELY_NEXT_BOTTLENECK = MIXED
PRODUCTION_CHANGE = NOT_AUTHORIZED
TRAINING = NOT_AUTHORIZED
```

**判定说明（按任务冻结规则）：**
- 冻结规则：`>= 4/6 LEAF_REPRESENTATION_SUPPORTED` → LEAF_REPRESENTATION；
  `>= 4/6 SEARCH_HORIZON_SUPPORTED` → SEARCH_EFFICIENCY；否则 MIXED。
- 本批：LEAF_REPRESENTATION_SUPPORTED = 1（< 4/6）、SEARCH_HORIZON_SUPPORTED = 0（< 4/6）、
  UNRESOLVED = 2（计算不可行）→ **正式输出 MIXED**。
- **但定性证据强烈偏向 LEAF_REPRESENTATION**：
  1. G19T7（唯一完全判明的 avoidable-failure root）：Hybrid leaf 把 unsafe 计划评为全场最高，
     safe 计划评得更低 → **直接 leaf 盲区证据**（不是 horizon：safe 计划同一 depth-1 可达）；
  2. G17T2：deeper Hybrid 把 safe 变 unsafe（leaf 梯度把猫引离走廊）→ CORE_WORSE，leaf 一致；
  3. SEARCH_HORIZON_SUPPORTED = 0（没有任何 root 显示"更深 Hybrid 修好 prod-unsafe"）；
  4. G18 对照在 pre-pickup root 同样无法用 leaf 分离 safe/unsafe。
- 因此 MOST_LIKELY_NEXT_BOTTLENECK 报告为 **MIXED**（正式规则），并明确注明
  **qualitative 主方向 = LEAF_REPRESENTATION**；下一阶段若想升级到 LEAF_REPRESENTATION 的
  正式判定，需先解决 oracle 的计算可扩展性（G28T9/G31T6）或补充更多可完成 root。
