# G0.4F-2A.4 — Board Piece Alignment UI Hotfix

日期：2026-08-30
HEAD：b07ab55（未 commit，Board.tsx 视觉布局修复，非玩法/非 AI/非引擎改动）

真人复测确认 F2A.3 黄屏已消失，但出现新的 UI regression：猫鼠 sprite 视觉上整体向上偏移，不再处于所在格子正中央（逻辑坐标正确，视觉 overlay 与格子中心错位）。

---

## 1. ROOT CAUSE

**ROOT_CAUSE = NORMAL_FLOW_CELL_ENTITY_WRAPPER**

F2A.1 为 ghost layering 新增的 `cellItemStyle`：
```ts
const cellItemStyle: React.CSSProperties = {
  position: 'relative',   // ← 普通 flow flex item
  zIndex: 1,
};
```
它让每个 grid cell（flex container）的实体内容（box/pile/butter/trap/tunnel...）被包进一个**普通 flow child**，参与 grid cell 的盒模型 / min-content 尺寸计算，改变了 track sizing 与 cell 内容几何；而猫鼠 `pieceStyle` 是独立 absolute overlay（top/left = r/rows·100%，纯百分比，**F2A 前后未改**），两者基准不一致 → 视觉错位。

`catPosition` / `mousePosition` / pieceStyle 数学均未变（已验证）。

## 2. 修复

按任务 §2 将 `cellItemStyle` 改为**真正的 full-cell absolute entity layer**：
```ts
const cellItemStyle: React.CSSProperties = {
  position: 'absolute',
  inset: 0,                                   // 全 cell 为 containing block
  zIndex: 1,
  display: 'flex',
  alignItems: 'center',
  justifyContent: 'center',
  pointerEvents: 'none',
};
```
- 完全脱离 grid cell 的 normal flow → 不再影响 track sizing / cell 盒模型。
- `cellImgStyle`（90%×90%）现在有明确 containing block（全 cell），真正相对格子计算并居中。
- box / pile / trap / entity butter / tunnel 全部仍格内居中（§3）。

**未改动**：
- ghost underlay（`ghostUnderlayStyle` absolute inset 6% zIndex 0）保持（§4）。
- 猫鼠 `pieceStyle`（absolute，width/height=100/cols%,100/rows%，left/top=c/cols·100%,r/rows·100%，zIndex 10）数学未改，**无 translate/marginTop/pixel compensation**（§5）。
- grid 保持 `repeat(N, 1fr)`——由于实体层和 ghost 都已 absolute，cell 无 in-flow 内容，1fr track 严格等分；未无理由加 `minmax(0,1fr)`（§6）。
- desktop 与 mobile/narrow 两处 grid render 都复用 `renderCell()` + `pieceStyle()`，修复同时覆盖（§7）。

## 3. 对照 F2A 前 geometry（§8）

pieceStyle 数学（top/left/width/height 百分比 + zIndex10 + flex center）在 F2A.1/F2A.4 均未改变；本轮只把 F2A.1 新增的 normal-flow wrapper 改为 absolute，使 ghost layering 不再改变原有棋盘 geometry。
