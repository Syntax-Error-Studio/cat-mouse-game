## §15. 不只看最后一个回合——前序回合审计

**crucial**：在 final root 无解之际，检查 T10/T11/T12（final root 之前 3 个猫回合）。早期工具报告"这些回合存在 defensive blocker"——**经本次精确复核，该结论需纠偏**：

- 精确复核（real oracle + 全量枚举）：T10=3 unique boundaries 全部 IMMEDIATE_MOUSE_WIN=false；T11/T12 同样如此（40 unique boundaries 全部 false）。但注意 **boundary 数量极小**（T10 3、T11 3、T12 40）表明：这些回合的鼠并未处于"下一回合可赢"的临界（rootMouseWinRoute=15→11→7，均 >> 3 步 carrying 预算）。
- **解读修正**：T10-12 的所有完整猫回合导致 IMMEDIATE_MOUSE_WIN=false，**不是因为猫推箱建了防线，而是因为鼠当时离洞门还远（route 15→11→7），任何完整猫回合后鼠 3 步都到不了洞**。所谓"blocker"在 T10-12 是平凡成立的，**不能**作为"存在有效防守"的证据。
- **production 在这些回合也没犯错**（T12 production DLL，boundary 同样 IMMEDIATE_MOUSE_WIN=false）。

**EARLIEST_PREVENTABLE_TURN 语义修正**：严格按 §3 的 IMMEDIATE_MOUSE_WIN oracle，**不存在**任何"猫可以用盒子堵住鼠下一回合得手"的前序回合（T10-12 鼠本来就不会下一回合得手；T13 已无力回天）。

## §18. Root-cause 分类

候选逐条判定：

- **CASE A BOX_LEAF_BLIND**：不成立（本局最终 root 无 blocker 可"排错"；leaf 排序在无解局面下无意义）。
- **CASE B SEARCH_HORIZON**：部分成立但语义不同——D2+ 才揭示 forced loss（100ms 只完成 D1），但 deeper search **不提供更优解**（都是 mate=mouse）。所以是"horizon 遮蔽了失败不可避免性"而非"horizon 遮蔽了更优防守"。
- **CASE C REFUTATION_CANDIDATE_COVERAGE**：不成立。
- **CASE D REFUTATION_MISCLASSIFICATION**：不成立。
- **CASE E PREVIOUS_TURN_FORTIFICATION_MISS**：**不成立（严格意义上）**——T10-12 中没有任何"当时推箱即可阻止鼠最终取胜"的精确证据；那些回合的"blocker"平凡成立（鼠本来下一回合不赢）。用户看到的"最后一两步"恰是 T12→T13 的转折：T12 末鼠 route=7，T13 开鼠已持黄油站 (9,8) route=1——**转折发生在鼠自己的回合**（T12 猫回合后 → 鼠回合拿黄油并移动到 (9,8)），猫在 T12 无法预知鼠会拿到哪块黄油/走向哪个洞格（幽灵黄油随机）。
- **CASE G USER_BLOCK_NOT_VALID**：成立（final root 及全局，无法用箱子堵住鼠——推箱威胁对 s 鼠洞格无效、且时机上无有效防线）。

**ROOT_CAUSE = USER_BLOCK_NOT_VALID（CASE G）为主**，辅以：
- PRODUCTION_DEPTH_LIMIT = MATERIAL（100ms 只完成 D1，看不到 forced loss，因此 AI 无法"知道已输"——但即便知道也无可改进走法）；
- 鼠致胜窗口完全在猫行动之外的幽灵黄油随机性 + 鼠路径自由选择中形成（T12→T13 一步跨过临界）。

**关键诚实结论**：用户提出的"最后一步用箱子堵路"的更优解，**按 GAMEPLAY 规则不存在**。这不是"AI 该做却做不到"，而是"任何猫在该局面都无法阻止鼠"。box-defense 表示缺口（§10 BOX_DEFENSE_REPRESENTATION=ABSENT）是真的，但在本局它不是可挽救失败的原因。
