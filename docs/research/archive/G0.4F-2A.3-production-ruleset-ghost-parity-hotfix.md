# G0.4F-2A.3 — Production RuleSet Ghost Parity Hotfix

日期：2026-08-30

## 1. ROOT CAUSE（已定位）

生产 Hard AI 用 `computeCatAiTrajectory()` → `planHardCatTurn(current, { rules: createEngineRuleSet(), ... })` → **`src/game/engine.ts` 的 `createEngineRuleSet()`**，而非 `ai/searchRules.ts` 的 `defaultRuleSet`。

但 `createEngineRuleSet()` 仍保留**旧黄油语义**：
- `enumerateButterSpawns` 没把 `pendingButterSpawns` 作为 reserved（ghost 可与实体黄油重叠）；
- `buildButterChance` 仍生成 **entity butter**（`butterPositions: [...state.butterPositions, c]`）—— 旧"拾取→立即补实体黄油"；
- **完全没有 `resolveGhostBoundaryChance` 字段**。

而 F2A.1 `simulator.ts` 的 hard safety：CAT→MOUSE boundary 且存在 `pendingButterSpawns` 或 `pendingButterPlacementDebt` 时，必须调用 `rules.resolveGhostBoundaryChance`，否则 **throw** `'RuleSet missing resolveGhostBoundaryChance for CAT→MOUSE ghost/debt boundary'`。

→ 生产 Hard 搜索只要模拟到猫最后一步 → CAT→MOUSE boundary 就 throw → React UI 消失 → **黄屏**。与真人复现"吃黄油后进入下一猫回合立刻黄屏"完全一致。

**ROOT_CAUSE = CREATE_ENGINE_RULESET_GHOST_RULE_DRIFT**

## 3. 修复：共享 ghost-rule enumeration kernel（ONE SOURCE）

### 3.1 engine.ts 新增导出的纯规则枚举器（§5/§6）
```ts
export function combinations<T>(cells, k)                       // uniform k-subsets
export function enumerateButterSpawnsForState(state)            // reserved = pendingButterSpawns
export function enumerateGhostAnnouncementOutcomes(state)       // pickup: ghost+1 uniform 1/N；N=0 → debt+1 deterministic
export function enumerateGhostBoundaryOutcomes(state)           // CAT→MOUSE: 0/partial/full, uniform k-subsets, 绝不 Math.random
```
放在 engine.ts（engine 不能 import searchRules 会成环；searchRules 已 import engine，可复用）。**非 AI 策略，是 gameplay rule enumeration。**

### 3.2 createEngineRuleSet 完整接入（§7）
```ts
export function createEngineRuleSet(): RuleSet {
  return {
    mouseStep, catMove, mouseSkill, catPlaceTrap, chooseTunnelExit, endTurn, // 真实 engine 函数
    enumerateButterSpawns: enumerateButterSpawnsForState,
    buildButterChance: enumerateGhostAnnouncementOutcomes,
    resolveGhostBoundaryChance: enumerateGhostBoundaryOutcomes,
  };
}
```
- 旧 `butterPositions: [...state.butterPositions, c]`（pickup 直接补实体黄油）**已彻底移除**（§12 搜索确认 0 hits）。
- 合法 materialization（boundary 把 ghost 加入 butterPositions）不受影响。

### 3.3 defaultRuleSet 同样复用 shared helpers（§8）
`ai/searchRules.ts` 删除了本地 `enumerateButterSpawnsForState` / `buildButterChanceForState` / `resolveGhostBoundaryChanceForState` / `combinations`，改为引用 engine 导出的共享 kernel。**不再存在两套 ghost chance 实现。**

REAL game（`mouseMove` 选择 ghost 位置 / REAL `endTurn` reroll-replacement）仍允许真实 `Math.random`。本轮只保证 **SEARCH paths** 用 explicit outcomes（`createEngineRuleSet` 的 buildButterChance / resolveGhostBoundaryChance 均不调用 Math.random）。
