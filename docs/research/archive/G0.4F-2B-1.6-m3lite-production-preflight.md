## 8. Production Progress Guard（§16-§28，hardTurnPlanner.ts runProgressGuard）

运行序：**main search → bounded refutation → Progress Guard**（超窄门）。

Eligibility（§19）：hard ∧ leafMode=baseline_hole_corrected ∧ enabled ∧ mouseHasButter ∧ pendingGhosts==0 ∧ debt==0 ∧ search.mate==null ∧ completedDepth>=2 ∧ previousCompletedPlan 存在。

Refutation 交互（§20）：仅 `selectedPlanSource=='baseline'` 且（若无 refutation 或 baselineProbeStatus=='NO_REFUTATION_FOUND'）才进入；override / PLAN_REFUTED / INCOMPLETE / CHANCE_MIXED → **SKIP**（P17/P18 验证）。

Trigger（§8/§21）：prev no-progress loop + current plan no-progress loop + signature 相等 + mouseTurnObserved。R1 = previousCompletedPlan（§22，只用 R1，禁用 R2）。

Safety（§23-§26，全部真实规则）：
- rescue replay legal / complete / NON_LOOP（不过则 skip）；
- **EXACT immediate mouse wins = 0**（真实 Mouse full-turn 枚举，非 greedy）；
- **rescue bounded probe = NO_REFUTATION_FOUND**（否则 fail-closed 保持原 plan）。

Budget（§27）：guard 只用 total-turn 剩余时间；deadline 到达 → abort 保持原 plan（P20 验证）。
