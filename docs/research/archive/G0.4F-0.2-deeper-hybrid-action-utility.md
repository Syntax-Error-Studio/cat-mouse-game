## 9. Action utility 判定（任务 §9）

按冻结判据（不因 evaluate score 更高判 positive；只看 terminal threat）：
- **A**（prod mouse-win-this-turn=true 且 deep=false）：全 root 均 prod=false → 无。
- **B**（prod THREAT_D1/D2 mate=mouse 且 deep != mouse）：全 root prod mate=null → 无。
- **C**（prod 可本回合拿黄油，deep 阻止且无新 immediate win）：全 root 两 arm 都可拿黄油 → 无。
- **WORSE**（deep 新增 mouse mate / immediate win / pickup）：全 root 无。

```
COMPARABLE_ROOTS = 6
DEEP_ACTION_CHANGED（首动作变）= 4；完整计划变 = 6
UTILITY_POSITIVE = 0
UTILITY_NEUTRAL = 6
UTILITY_WORSE = 0
UNRESOLVED = 0
```

**解释：deeper Hybrid 在 6/6 失败 root 改变了完整猫计划（4/6 改变首动作），但 terminal-only
threat 与 immediate mouse-turn 结果在两个 arm 上完全相同（无即时鼠胜、无 D1/D2 mate、两 arm
都允许本回合拿黄油）。** 因此更深搜索选出的动作**没有降低鼠的近期获胜威胁**。

## 10. Verdict（任务 §10）

**冻结规则：**
- `UTILITY_POSITIVE / DEEP_ACTION_CHANGED >= 0.60 且 UTILITY_WORSE = 0` → ACTIONABLE。
  本批：UTILITY_POSITIVE = 0 → 比值 0/6 = 0 < 0.60 → **不满足 ACTIONABLE**。
- `UTILITY_POSITIVE <= 1` → **LOW_VALUE**（直接命中）。

```
SEARCH_DEPTH_CEILING = LOW_VALUE
```

**含义：在当前这批 pre-pickup 真人失败 root 上，把 Hybrid 搜索加深到 D2/D3（乃至 D4，但 D4
本就计算不可行）并不能带来任何可观察的近期威胁降低——深搜的 utility 天花板是 LOW_VALUE。
因此"继续优化深搜去拿这些 deeper decisions"没有价值。**

**注意范围**：THREAT_D2 的视野是"鼠回合 + 猫回合"，对于"鼠拿黄油→下一回合冲洞"这种
2 个鼠回合 + 1 个猫回合的威胁，D2 视野尚未覆盖到（这也解释了为什么这些 root 上没有 mate）。
LOW_VALUE 判定针对的是 **terminal-only 意义上的即时威胁**；它说明的是"在 D2/D3 范围内更深
的 Hybrid 没有即时效用"，不代表"更深的 mate 证明永远不可能"（G18 T12 证明深度够会出 mate）。

> **ERRATA（G0.4F-0.3 修正，2026-08-29）**
> **SEARCH_DEPTH_CEILING = LOW_VALUE 的范围必须固定为 `D2_TERMINAL_THREAT_CEILING = LOW_VALUE`。**
> 原因：本批 THREAT_D2 只覆盖 `Mouse → Cat`（1 个鼠回合 + 1 个猫回合），**没有覆盖
> `Mouse → Cat → Mouse`（2 个鼠回合 + 1 个猫回合）**——即"M1 拿黄油 → 猫防守 → M2 冲洞获胜"
> 这一真人失败的核心机制完全不在 F0.2 的 THREAT_D2 视野内。因此：
> - F0.2 的 UTILITY_POSITIVE=0 / LOW_VALUE **只能**解释为"D2 终端威胁视野内的深搜天花板低"；
> - **禁止用它单独证明 LEAF_REPRESENTATION 已是最终主因**；
> - 核心机制判别由 **G0.4F-0.3** 的 `FORCED_PICKUP_WIN_BY_NEXT_MOUSE_TURN`（∃M1 ∀C1 ∃M2 : MouseWins）
>   直接覆盖 M1→C1→M2 三段，并回溯到 LATEST_AVOIDABLE_ROOT 后再判定 leaf/horizon。
