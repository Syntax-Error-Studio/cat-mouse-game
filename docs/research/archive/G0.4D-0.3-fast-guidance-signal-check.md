## 5. Interpretation

- **GUIDANCE_INFORMATION_CONTENT = LOW**: the T3 consensus top-set carries little pruning
  information (72% of roots: "all actions are in the top set"). A model trained to predict it
  would be predicting a nearly-constant, non-informative target.
- **EXISTING_VALUENET_GUIDANCE_SIGNAL = WEAK**: the frozen ValueNet, used as a one-step
  ordering heuristic (cat-max / mouse-min), hits the consensus top-set 86-91% but random does
  84-87% — negligible lift. It does NOT provide a usable move-ordering signal.
- The earlier D0.2 "top-set consensus is strong (0.935/0.831)" was about STABILITY (the same
  top-set is stably identified across depths), NOT about USEFULNESS (the top-set is too broad
  to prune). These are now distinguished.

## 6. Target decision

- T2 (pairwise rank) already rejected (D0.2: coverage 0.072, tie-dominated).

- **NEXT_STEP = STOP_SEARCH_GUIDANCE** — neither the consensus top-set nor the existing
  ValueNet yields a usable move-ordering signal on this data. No further search-guidance work
