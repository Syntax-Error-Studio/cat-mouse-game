## 1. Integration architecture (§1–§2)

**New module boundary** `src/game/ai/boundedPlanRefutation.ts` — NOT inside
`expectiminimax.ts`; primary search mathematics untouched. It owns ONLY:
candidate cat-plan enumeration (frozen G0.3U selector, MAX 6), cheap candidate
selection, bounded mouse adversarial probe (frozen G0.3V), legal refutation
witness (replay gate §8), conservative override (§5). Dependency rule honored:
engine is type-only; the module receives the injected `RuleSet` (never imports
`ai/searchRules.ts`).

**Hard planner wiring** (§2): `planHardCatTurn` runs the existing production
legacy search first (STEP 1 — unchanged budget `timeBudgetMs=100ms`, same
iterative deepening / AB / TT / ordering / evaluator / G0.3A/G0.3E plan
extraction). Then, only when `refutation.enabled` (STEP 2 gate via
`shouldRunSidecar`):

| gate | condition |
|------|-----------|
| difficulty | == hard |
| phase | == playing |
| currentPlayer | == cat |
| baseline plan legal | search.completed ∧ plan.length > 0 |
| baseline completed | search.completed |
| baseline mate | == null (mate=cat / mate=mouse → `mate_bypass`) |
| flag | == ON |

STEP 3: bounded sidecar (`runRefutationSidecar`) — per-candidate probe with
per-candidate internal caps (32 paths / 20ms / 16 exact) PLUS the external
total-turn deadline (`totalTurnBudgetMs`). STEP 4: only a full conservative
override decision replaces `catTurnPlan`, after the cat candidate replays legal
(§9). The baseline search budget is NEVER changed (spec §19).

**Probe status** (§3): `PLAN_REFUTED` (full legal witness) /
`NO_REFUTATION_FOUND` (bounded contract completed) / `CHANCE_MIXED` /
`INCOMPLETE` (outer deadline/abort). `INCOMPLETE` can never act as an override
candidate and never leaks a partial positive (spec §3, §7).

**Diagnostics** (§16): compact `refutation` field on `HardSearchDebug` (scalars
+ short token arrays only; excluded from stateKey like the rest of the debug
record). Fields: `refutationEnabled, refutationTriggered, candidateCount,
baselineProbeStatus, baselineRefutationWitness, candidatesProbed,
candidateStatuses, pathCount, exactLocalChecks, refutationCpuMs,
refutationWallMs, overrideEligible, overrideUsed, selectedPlanSource,
sidecarAbortReason`.

**Feature flag** (§21): `refutation: { enabled: boolean; totalTurnBudgetMs? }`
in `HardTurnPlanOptions`. Default OFF. Easy/Medium never take this path. No
user-visible UI setting.

## 4. Deadline semantics (§6, §7)

- `totalTurnBudgetMs` is the TOTAL turn budget (baseline + sidecar). The
  baseline always runs with its unchanged 100ms budget first.
- The sidecar runs only if the remaining time is positive; every mouse-path
  expansion, exact-local check, and candidate switch samples the external
  deadline. On deadline: the probe returns `INCOMPLETE`, the unfinished
  candidate's negative is discarded, and only a fully-completed override
  decision may fire; otherwise fall back to baseline (no partial leakage).
- The module's per-candidate internal caps (32/20ms/16) are independent and
  frozen (spec §23 — no threshold/parameter tuning).

## 5. Tests (§22) — 13 required

`src/game/ai/__tests__/boundedPlanRefutation.test.ts` — all 13 pass:

1. **disabled = baseline identical** — flag absent vs `{enabled:false}` → same plan/value/mate/bestAction, `debug.refutation` undefined.
2. **mate=cat bypass** — adjacent-capture state → `mate_bypass`, sidecar never triggers.
3. **mate=mouse bypass** — `shouldRunSidecar` gate returns false for mate=mouse; true for mate=null+enabled.
4. **G4 BAD refuted** — real corpus: URPTDR → PLAN_REFUTED, witness DDR, pathRank 1.
5. **G4 candidate override** — sidecar overrides BAD → RRRR, candidate replays legal.
6. **G1T2 all-refuted no override** — real corpus: 6/6 PLAN_REFUTED → no override.
7. **G1T1 baseline-not-refuted no override** — real corpus: baseline not refuted → no override.
8. **external deadline → INCOMPLETE** — deadline in past → INCOMPLETE, never a completed negative.
9. **INCOMPLETE cannot override** — comparator picks NO_REFUTATION_FOUND over INCOMPLETE; all-INCOMPLETE → 0.
10. **invalid witness cannot override** — invalid-witness baseline → pickOverride returns 0.
11. **invalid cat candidate cannot execute** — `replayCatCandidate` rejects mouseStep / wall step.
12. **chance mixed not guaranteed** — butter pickup on the only win route → CHANCE_MIXED (never deterministic PLAN_REFUTED).
13. **trap/skill/tunnel witness replay legality** — skill+trap-step witness valid; skill-without-butter invalid; catPlaceTrap in a mouse witness invalid.

Real-corpus tests (4-7) load via `g03o_lib.parseGames` and are explicitly
`ctx.skip()`-ped when the log is absent (never a vacuous pass). Full suite:
**236 tests pass, tsc clean.**

**Test 12 exposed a latent correctness bug fixed in the module**: a terminal
mouse win reached *behind a CHANCE node* was reported as PLAN_REFUTED; per §3
(chance = AND over all positive-prob outcomes) it is now `CHANCE_MIXED`
(`bestType = hasChance ? 'B' : 'TERMINAL_WIN'`). G4's DDR refutation is
deterministic (type A) so the causal gate is unaffected.

## 8. Chosen trial budget (§18)

**`TRIAL_BUDGET = 150ms`** (MIN_STABLE_TOTAL_BUDGET). Rationale: 150ms already
achieves 10/10 sidecar completion, 10/10 override of the authoritative BAD
plan, and 10/10 not-BAD — the smallest stable total budget. Per §18 the budget
is chosen as the smallest stable one, NOT 500ms; the 100ms baseline search
budget is unchanged. This is a trial configuration for human playtesting, not a
permanent product decision.

## 10. HUMAN_VALIDATION_PROTOCOL (§25)

Do NOT announce "Hard is fixed". Next step: a human plays **10 real Hard games**
with the feature ON at `TOTAL_HARD_TURN_BUDGET_MS = 150` (flag:
`refutation: { enabled: true, totalTurnBudgetMs: 150 }`). Per game record:

- win/loss
- per-turn override count (`debug.refutation.overrideUsed`)
- per-turn PLAN_REFUTED count (`baselineProbeStatus === 'PLAN_REFUTED'`)
- baseline vs selected plan (`selectedPlanSource`)
- sidecar CPU/wall (`refutationCpuMs` / `refutationWallMs`)
- any: obvious stalling / illegal moves / strange circling / wrong override

Compare qualitatively with the prior post-G0.3H 5/5 mouse-win human session —
**not as a strict statistical A/B** (boards and player decisions differ). The
trial's pass criteria for humans: no illegal moves, no stalling, no observable
regression vs the flag-OFF behavior, and a plausible win-rate improvement.
