## 0. Proof-rule correction (Stage B0 §1)

The earlier working rule **"find one forced boundary ⇒ that cat plan is NOT_ESCAPE"
is NOT generally valid.** It holds only when the MOUSE can deterministically
*choose* to steer into that boundary:

- case A: a deterministic/adversarial mouse edge leads directly to a
  `PROVEN_FORCED_LOSS` boundary (mouse picks it), **or**
- case B: after the mouse picks an action, a CHANCE node is entered whose
  **every** positive-probability outcome eventually lands in a
  `PROVEN_FORCED_LOSS` boundary.

A forced boundary that is only reachable as **one part-outcome of a chance
node** (other outcomes avoid / are unresolved) is **STOCHASTIC_MIXED** and
yields **UNRESOLVED**, never NOT_ESCAPE. Chance outcomes are NOT mouse choices.

Also: `value ≪ 0 ⇒ forced` is forbidden; `mate=null ⇒ safe` is forbidden.
`PROVEN_FORCED_LOSS` requires (as in G0.3O):
`completed=true` search and **every legal cat root action reports
`mate=mouse`** at the authoritative probe horizon (cd1..cd3, fresh full-window
context, deadline OFF, G0.3O methodology, `evaluateForCat` leaf).

## 1. Provenance-preserving tree (Stage B0 §2)

The analysis tree keeps the real node/edge structure produced by the G0.3K
`buildTurnDag` oracle — it is NOT flattened:

```
MOUSE_DECISION                  (mouse legal actions; MIN node)
   ├─ mouseAction=ArrowUp   →  (next MOUSE_DECISION | CHANCE | NEXT_CAT_BOUNDARY)
   ├─ mouseAction=…          …
   └─ mouseAction=mouseSkill …
CHANCE                         (butter respawn; edge weight = outcome probability)
   ├─ outcome w=1/N → …
   …
NEXT_CAT_BOUNDARY              (stateKey ⊗ cumulativeCost nodeKey, prob, hasChance)
```

Decision branches and chance outcomes are never merged before judgement; the
aggregation in §4 works directly on this tree.

## 3. Boundary predicate (Stage B0 §5)

A `NEXT_CAT_BOUNDARY` state may only be classified:

- **PROVEN_FORCED_LOSS** — authoritative exact proof (per §0): all legal cat
  root actions `mate=mouse`, completed, cd≤3.
- **NOT_PROVEN_FORCED** — all cat root actions fully resolved and ≥1 is exact
  non-mate at cd≤3.
- **PROBE_UNRESOLVED** — any required probe hit the node/wall-clock cap.

## 4. Aggregation rules (Stage B0 §6, §7)

Upward aggregation over the provenance-preserving tree (four truth values:
`MOUSE_CAN_FORCE_PROVEN_REGION` / `AVOIDS_PROVEN_REGION` / `STOCHASTIC_MIXED` /
`UNRESOLVED`):

- **MOUSE_DECISION** → `MOUSE_CAN_FORCE_PROVEN_REGION` iff ≥1 child is
  `MOUSE_CAN_FORCE_PROVEN_REGION` (mouse actively chooses it); else
  `UNRESOLVED` if any child is `STOCHASTIC_MIXED` or `UNRESOLVED`; otherwise
  (ALL children `AVOIDS_PROVEN_REGION`) → `AVOIDS_PROVEN_REGION`.
- **CHANCE** → `FORCED_WITH_CERTAINTY` iff ALL positive-probability outcomes
  are `FORCED_WITH_CERTAINTY` / `PROVEN_FORCED_LOSS` (probability outcomes are
  never mouse choices); `STOCHASTIC_MIXED` if some forced + some
  avoid/unresolved; `AVOIDS_PROVEN_REGION` if all outcomes avoid.

**Sufficiency (which boundaries can prove NOT_ESCAPE):** only case A
(deterministic edge) or case B (chance node, ALL positive-prob outcomes forced).
A single low-probability forced outcome is insufficient.
