## §2 Engine (ai-training/f2b19ai/ai_lib.mts)

Turn-level AND-OR safety game, conservative for cat, chance = ALL positive-probability
outcomes:

- `SAFE(catRoot, d) = ∃ cat full-turn plan P: ∀ mouse full-turn replies (choices ×
  chance): SAFE(nextCatRoot, d-1)`; terminals MouseWins→UNSAFE, CatWins→SAFE.
- `SAFE(catRoot, 0)` = base case ≡ frozen `planEndSafe` (METHOD_A_FROZEN
  f2b19c_oracle.sha256=40fa1305ca3e) applied at root level: ∃ plan with
  `ALL_OUTCOMES_SAFE`.
- Node types: catRoot = OR (cat picks), mouse reply = AND (all replies must be safe).
- Memo: stateKey → {safeAt, unsafeAt} with depth-monotone semantics (UNSAFE@d ⇒
  UNSAFE@d'>d; SAFE@d ⇒ SAFE@d'<d). UNRESOLVED never memoized.
- Budgets: wall deadline, per-plan caps, per-root wall; quickRefute (frozen G0.3V/1.9O
  bounded scout) as a *sound* refutation pre-filter for runtime tiers only — authority
  gates run exact (quickRefute=false).

**Convention fix (critical):** the frozen authority convention is
`planEndSafe(ruleSet.catMove-replay pre-boundary end)` (f2b19g_lib.frozenVerdict);
replaying with `simulateSearchAction` yields a post-boundary mouse-to-move state and
`analyzeEndState` then double-endTurns → false ALL_OUTCOMES_SAFE (G1T10/UUUU initially
mislabelled SAFE; fixed to IMMEDIATE_MOUSE_WIN matching 1.9H-R1). Engine replays cat
plans via the raw ruleSet primitives (pre-boundary) — parity with the frozen oracle.

## §10 Verdict

1. **RECURSIVE_CORRECTION = TRUE.** The frozen depth-1 per-plan "SAFE" labels
   (METHOD_A_FROZEN planEndSafe; used as ground truth across 1.9O–1.9AH) are
   over-optimistic in at least the G1T9/DRDD case: after DRDD the mouse replies
   D→R→R to R* (cat(6,6)/mouse(9,6) carrying) where EVERY cat plan is depth-1-BAD
   (37/38 ends immediately winnable, the blocking plan loses structurally). The
   depth-1 `NOT_FORCED` ∃-boundary criterion is not a real strategy. **The 1.9D/1.9L
   "G1T9 horizon case, DRDD = the safe plan" narrative holds only at depth-1; at
   depth-2 G1T9 has no certified-safe continuation.**
2. **SAFE@2 CONFIRMED for 3/8 dev refs** (G1T1/TRDDD 246ms, G8T5/URLU 26.8s,
   G4T2/RRDD 716s) — the 1-ply criterion is adequate there; 4/8 UNRESOLVED (budget).
3. **AND-OR ORDERING CAUSAL GAIN = TRUE at threshold (5/8 vs 3/8)**, conditional on
   threat presence; all-safe roots degenerate to beam order (regression vs AH).
4. **RUNTIME = CONDITIONAL, NOT GENERAL**: bounded AND-OR certification rescues within
   100-150ms exactly when a cheap-to-certify safe plan exists in the beam (G8T9 10/10
   @100ms — fixes the 1.9U SAFE_TO_BAD failure; G8T10 10/10 @150ms via DRUR); G1T9-class
   roots remain uncertifiable in budget. **SAFE_TO_BAD = 0 by construction** (SAFE only
   via exact planEndSafe).
5. **Authority use**: the turn-level AND-OR engine is a sound depth-parameterized
   certifier; its depth-2 pass should re-certify the frozen corpus before any further
   recall/ordering experiment treats "SAFE" as game-theoretic truth.
