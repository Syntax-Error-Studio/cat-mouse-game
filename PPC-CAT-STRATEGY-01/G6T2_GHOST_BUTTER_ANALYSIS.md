## 3. 这段鼠线到底靠什么成立（节奏赛实测）

同一段鼠行动（技能 + 六次下行）对三种猫开局的实测结果（`CAT_DEFENSE_WITNESSES.tempoRaceTable`）：

| 猫开局 | 猫落点 | 鼠是否走得通 | 鼠落点 | 第 2 回合开始时猫鼠距离 | 猫能否一回合抓到（预算 4） |
|---|---|---|---|---|---|
| **UURR**（历史选择） | (1,5) | 通 | (7,6) | **7** | **不能** |
| DRRR | (4,6) | **被挡**（第 3 个 D 非法，鼠停 (3,6)） | — | 1 | 鼠已无法继续 |
| DRDR | (5,5) | 通 | (7,6) | **3** | **能** |

> 注意基准：第 2 回合开始时猫的步数被 `endTurn` **补满**为 `catBaseMoves = 4`；
> 回合末的 `catMovesLeft` 已经是 0，不能拿来当抓捕预算（本项目踩过这个坑）。

**结论（可直接写进架构文档）**：
- 猫要走得通的前提不是"守住 (4,6)"，而是 **自身回合结束时与鼠的落点距离 ≤ 4 且路径通畅**。
- UURR 把猫留在 (1,5)，与鼠落点相距 7 ⇒ 下一回合 4 步根本够不到 ⇒ 鼠白拿一个回合。
- DRRR 直接占住鼠的南向通道 (4,6)（物理阻断，鼠第 3 个 D 非法）。
- DRDR 留在 (5,5)，距离 3 ⇒ 下一回合先手落子即可抓捕。
- 这三条都是**具体着法层面**的事，和评价函数无关。

## 4. 幽灵黄油在这一局到底是什么角色（重要的否定结论）

鼠在 (2,6) 拾取实体黄油时，会公告一个新幽灵。公告集合：**29 个候选**，均匀 `1/29`，权重和 = 1（误差 < 1e-12）。

候选里确实有两条猫的反击走廊格：

```
corridorCells = 4,5 / 4,6 / 4,4
corridorHitByGhost = 4,4 / 4,5        （4,6 因距鼠 2 步 < 3 被排除）
```

若幽灵落在 (4,4)/(4,5)，物化后成为**实体黄油**并阻挡猫的移动（`canCatStepTo` 排除黄油格）。看起来像"幽灵替鼠挡猫"。

但把 29 个分支**逐条**送进精确量词搜索后：

| 分支数 | 仍然"鼠强制胜"的分支 | 未判定分支 |
|---|---|---|
| 29 | **29 / 29** | 0 |

**因此：本局的鼠胜不依赖幽灵落点。** 即使 29 个分支里一个都没落在走廊上，鼠依然在每个分支都能强制获胜。
历史叙述把"幽灵黄油"当作诱敌机制的核心，在 G6T2 这个具体局面上**不成立**；幽灵黄油在这里只是位置层面的战利品，不是胜负原因。

> 这条否定结论很重要：它阻止我们围绕"幽灵挡路"去造一个新特征，而去造一个用不上的东西。

另外两个 CHANCE 事实：
- `UURR` 之后的 CAT→MOUSE 边界 CHANCE **只有 1 个正概率结果**（权重 1.0）：pending ghost (5,1) 的公告格空着，直接物化。所以"边界"也没有分支。
- 因此本局的随机性对结论**没有影响**：`MOUSE_FORCED_WIN_WITHIN_H1`，不是"抽到好签"。

## 6. 猫的防守线（最强见证）

H1 窗口下的防守线（`CAT_DEFENSE_WITNESSES.witnesses[0]`）：

```
c:D c:R c:D c:R ~chance#1 m:U m:D m:U c:U c:D c:U c:D m:D m:U m:D → HORIZON
```

逐动作回放通过，终局 `phase = playing`（视界内无人获胜），最大 `idx = 4`（正好到达 H1 边界）。

沿线的鼠回应覆盖（链上每个鼠决策点，枚举其**全部**合法回应并逐个验证"仍被挡住"）：

| 节点 | 鼠全部回应 | 是否全部被挡 |
|---|---|---|
| 猫(5,5) 鼠(0,6) | D / L / R / S | ✅ |
| 猫(5,5) 鼠(1,6) | U / D* / L / R / S | ✅ |
| 猫(5,5) 鼠(1,6) | U / D* / L / R / S | ✅ |
| 猫(5,5) 鼠(0,6) | D / L / R / S | ✅ |

（`*` = 该步转移为 CHANCE，即拾取公告。）

注意鼠线上出现了 `m:U m:D m:U` —— 鼠被迫**向上绕**，因为南向通道被猫封住。这就是"被赶离洞口"的可见形态。

第一回合的逐层安全集（`CAT_DEFENSE_WITNESSES.catDefenseActionSets`）：

| 层 | 走法 → 是否安全 |
|---|---|
| 第 1 步（根） | U → 不安全 · **D → 安全** · L → 不安全 |
| 第 2 步（D 之后） | U → 不安全 · L → 不安全 · **R → 安全** |

即：**猫第一回合必须先 D 再 R**，之后才有分支自由度（DRRR / DRDR 都安全）。

## 7. 给下一阶段的一句话

> G6T2 的教训不是"幽灵黄油很强"，而是"**猫在回合结束时必须仍然够得着鼠将要停的地方**"。
> 这是一个**时间性**事实（谁在第几回合落在哪、还剩几步），当前 H1 视界下能被精确证明，而 D1 的评价函数看不到。
